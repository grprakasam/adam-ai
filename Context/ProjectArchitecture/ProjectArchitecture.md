


**PROJECT GOAL**
Create a webapp for clincial programming to leverage the AI capabilities in  creating ADAM programs like ADSL, ADAE, ADLB,etc through Generative AI , instead of manual coding.
Build a very userfriendly DOMAIN Based -AI Pair Programming tool for ADAM Programs creation
Provide great user expereince for the ADAM program developers to work in a natural language way of generating programs

**SUCCESS CRITERIA **
Users feel that the tool is pure domain friendly tool to create ADAM programs
Generated ADAM programs like ADSL, or ADAE or ADLB must be as per the industry standards 
Genertad programs must be properly working when the proper SDTM inputs are given and run in either SAS or R Environments

**Expected Tool  Behaviour:**
It should take the role of an expert SAS Programmer or an expert R Programmer based on user choice
It should also be an ADAM programming expert in clearly understanding the domain 


**PROJECT DESIGN:**
A user friendly chatbot mode ui screen to interactively  understand user inputs through the 'ADAM Program Generator'Page
Get things confirmed at each level from the user (based on how it is defined under 'Context\ADAMRules')and  gradually build the final program
