# ADAM AI - Mobile & Responsive User Guide

## 🎯 Overview
ADAM AI now works seamlessly on all your devices - from your phone to your desktop computer. Here's how to get the most out of the app on different screen sizes.

---

## 📱 Mobile Experience (Phones)

### **Opening the Configuration Menu**
On mobile, the left configuration panel is hidden by default to give you more workspace.

**To open the menu:**
1. Tap the **☰ hamburger icon** in the top-left corner
2. The configuration panel slides in from the left
3. Tap outside the panel or complete an action to close it

### **Navigation**
- **Header**: Fixed at the top for easy access
- **Menu Button**: Always visible for quick access to configuration
- **User Menu**: Tap your profile icon in the top-right
- **Dark Mode**: Toggle available in top-right corner

### **Working with Forms**
- All input fields are optimized for touch
- Larger buttons (48px) for easy tapping
- No accidental zoom on input focus
- Scrollable sections with smooth touch scrolling

### **Tips for Mobile**
- ✅ Use portrait mode for forms and configuration
- ✅ Use landscape mode for viewing code and results
- ✅ Swipe to scroll through long content
- ✅ Auto-save works in the background

---

## 📱 Tablet Experience (iPads, Android Tablets)

### **Hybrid Layout**
Tablets get the best of both worlds:
- Configuration panel is visible but narrower (320px)
- More horizontal space for viewing code
- Collapsible panels just like desktop

### **Panel Management**
- **Collapse Left Panel**: Tap the collapse button (◀) on the panel edge
- **Expand Left Panel**: Tap the expand button (▶) when collapsed
- **Pair Programming**: Full workspace area available

### **Orientation**
- **Portrait**: Great for reading and configuration
- **Landscape**: Optimal for code viewing and pair programming

### **Tips for Tablet**
- ✅ Keep left panel collapsed when focusing on code
- ✅ Use landscape mode for side-by-side viewing
- ✅ Split-screen with documentation is fully supported
- ✅ External keyboard works perfectly

---

## 💻 Laptop/Desktop Experience (1024px+)

### **Full Workspace**
- **Left Panel (380px)**: Project configuration and settings
- **Right Panel**: Code generation and pair programming
- **Toggle Button**: Between panels for collapse/expand

### **Panel Controls**
- **Collapse Left Panel**: Click the ◀ button on the panel divider
- **Expand Left Panel**: Click the ▶ button when collapsed
- **Unlock Pair Programming**: Complete configuration steps

### **Keyboard Shortcuts** (Desktop Only)
- `Ctrl/Cmd + B`: Toggle left panel
- `Ctrl/Cmd + /`: Open help center
- `Ctrl/Cmd + Z`: Undo last change
- `Ctrl/Cmd + Shift + Z`: Redo change
- `Ctrl/Cmd + K`: Focus search

### **Tips for Desktop**
- ✅ Keep both panels open for maximum productivity
- ✅ Use keyboard shortcuts for faster navigation
- ✅ Multi-monitor setup: use full-screen on secondary display
- ✅ Browser zoom works perfectly (90%-150%)

## 🔄 Switching Between Views

### **Responsive Breakpoints**
The app automatically adapts based on your screen width:

| Screen Size | Layout Type | Left Panel Behavior |
|-------------|-------------|---------------------|
| < 768px | Mobile | Overlay drawer |
| 769px - 1024px | Tablet | Narrower sidebar |
| > 1024px | Desktop | Full sidebar |

### **Automatic Adjustments**
When you resize your browser or rotate your device:
- ✅ Layout instantly adapts
- ✅ Content remains in place
- ✅ No data loss
- ✅ Smooth transitions

## 🆘 Troubleshooting

### **Menu Not Opening on Mobile**
- Ensure JavaScript is enabled
- Try refreshing the page
- Clear browser cache
- Check for browser updates

### **Layout Looks Broken**
- Hard refresh: `Ctrl+F5` (Windows) or `Cmd+Shift+R` (Mac)
- Clear cache and cookies
- Try incognito/private mode
- Report issue with screenshot

### **Touch Not Working**
- Disable browser extensions
- Check touch screen calibration
- Try different browser
- Ensure touch is enabled in OS settings

### **Panels Overlapping**
- Resize browser window
- Rotate device
- Zoom out slightly
- Close mobile menu
