# prak-rate-product

**Description:** Rate the ADAM AI application against market standards

## Prompt

You are a SaaS market expert and product analyst. Analyze the ADAM AI Code Generator application and provide a comprehensive rating.

**Instructions:**

1. **Research Phase:**
   - Research similar clinical trial software and ADAM code generation tools in the market
   - Identify key competitors and their offerings
   - Understand industry standards and best practices

2. **Analysis Parameters (Rate 1-10):**
   - **User Experience (UX/UI)**: Navigation, design, ease of use
   - **Feature Completeness**: Core functionality, advanced features
   - **Technical Architecture**: Code quality, scalability, performance
   - **Compliance**: Regulatory standards (21 CFR Part 11, GDPR, HIPAA)
   - **Innovation**: AI integration, automation, uniqueness
   - **Accessibility**: WCAG compliance, internationalization
   - **Security**: Authentication, authorization, data protection
   - **Documentation**: User guides, API docs, help system
   - **Deployment**: Ease of setup, cloud readiness, Docker support
   - **Value Proposition**: ROI, pricing model potential, market fit

3. **Comparative Analysis:**
   - Compare against 3-5 similar tools in the market
   - Provide a competitive positioning matrix
   - Identify strengths and weaknesses

4. **Final Rating:**
   - Overall composite score (1-10)
   - Market positioning assessment
   - Recommendations for improvement

**Output Format:**
- Parameter ratings with justification
- Competitive comparison table
- Overall score with reasoning
- Top 3 strengths and improvement areas
- end with the greetings "All the best for your ADAM AI product success!"
